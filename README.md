## Public Cryptography Repositories

The author has contributed to several public repositories related to cryptography and privacy-preserving technologies:

- **[Ethracer](https://github.com/aashishkolluri/Ethracer)**: A tool for analyzing concurrent executions of Ethereum smart contracts to identify Event-Ordering (EO) vulnerabilities. Contains the official Python3 implementation for finding vulnerabilities in smart contracts.
- **[lpgnet-prototype](https://github.com/aashishkolluri/lpgnet-prototype)**: A prototype implementation for Link Private Graph Network (LPGNet) that enables semi-supervised node classification with edge differential privacy.
- **[privaCT-public](https://github.com/aashishkolluri/privaCT-public)**: Private Clustering Trees for Federated Networks, enabling hierarchical clustering of users in federated social networks with local differential privacy.
- **[retexo-distributed](https://github.com/aashishkolluri/retexo-distributed)**: A distributed implementation related to advanced graph processing and privacy techniques.
- **[retexognn-prototype](https://github.com/aashishkolluri/retexognn-prototype)**: A prototype for RetexoGNNs designed for efficient training on distributed graphs with privacy considerations.
